# Contributing

The full guide is on the website (Contribute page, source: `contributing.qmd`).

Quick version:

- **Small edits:** use *Edit this page* on the website → propose changes → pull request.
- **New method / case study / correction:** open an issue using the matching template.
- **New method page:** add rows to `data/methods.csv (and misuse warnings to data/misuse_rules.csv)`, copy `methods/_template.qmd`, add the page to `_quarto.yml`, open a pull request.
- **Case studies:** belong in the regional hub repositories (e.g. cecaf-assessment-catalogue).

Every pull request needs one approving review. Status `reviewed` requires CECAF working-group sign-off.
