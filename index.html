NFIFM Toolbox

Shared method library and code for stock assessment, from data to management advice

Development version. NFIFM Toolbox is a working title for the shared method library of the FAO Global Stock Assessment Capacity Programme. Content is draft and not an official FAO product.

Part of the Global Stock Assessment Capacity Programme

The programme links FAO’s normative work and global reporting with regional implementation platforms and six thematic workstreams, so that stock assessments routinely inform fleet capacity limits, effort management and harvest strategies. Its cross-regional learning hub connects regions and themes. The toolbox is the hub’s shared method library and code: the common place where methods, data tools, guidance and training material are documented once and used by every region.

Where the toolbox fits

Programme element What the toolbox provides
Cross-regional learning hub: shared method library and code The whole toolbox: data preparation, method selector, method catalogue, fishery indicators, advice and harvest strategies
Joint working groups; analyst and trainer exchange Training and apps, with the Stock Monitoring Tool as the main training environment; shared case studies

FAO normative work and global reporting (SOFIA, FIRMS, SDG 14.4.1) Common principles, model acceptance criteria and misuse prevention, so that status reported from different regions and data tiers is comparable
Developed-country partners: method partners and peer review Contributions through GitHub review and a proposed expert review panel

Every method is documented the same way. Each page follows the pipeline data → method → outputs, with diagnostics, sensitivity demos, worked examples and code, and an explicit use and misuse section: when not to use the method, pre-run checks, and the checks to pass before results are used for advice.

Philosophy

The toolbox follows a hierarchical assessment framework: one assessment logic and one set of biological assumptions across the data ladder, from length data only to catch, length and abundance indices; risk-equivalent advice whichever tier a stock is assessed at; and the value of information of each data source measured in simulated and real case studies.

From data to advice

1 · Prepare data → 2 · Select methods → 3 · Assess → 4 · Diagnose and check for misuse → 5 · Advice and HCRs

Start by preparing and inventorying the data, then use the method selector: describe your data (catch, indices, length or age composition, life history, gears, fishery) and it lists the candidate methods, the data you would still need for others, and the misuse warnings for your situation.

The toolbox by workstream

Workstream 1

Multispecies and multigear assessment

Multispecies MSY and mixed approaches, gear interactions, effort allocation and fleet capacity (mmsyFM).

Workstream 2

Data-poor and small-scale fisheries

Length-based and catch-only methods, SSF catch and effort monitoring, participatory data collection.

Workstream 3

Assessment to advice and harvest strategies

Stock status and reference points, standard advice formats, HCRs, capacity and effort limits, simplified MSE.

Workstream 4

Capacity building

National and regional mentoring, working groups, e-learning, training of trainers, with the Stock Monitoring Tool as the main training environment.

Workstream 5

Knowledge sharing and consensus

Shared methods and code, peer review, technical consultations, global reporting (SOFIA, SDG 14.4.1).

Workstream 6

National assessments ↔︎ RFMOs

Stronger national EEZ assessments, small-scale catches of RFMO-managed stocks, RFMO data obligations.

Regional platforms

The toolbox is shared across the regional implementation platforms (Asia, Africa, Latin America, SIDS, inland fisheries, with developed countries as partners); regional hubs add their own case studies, data and priorities. See Regional hubs. The first hub is the CECAF assessment catalogue (Africa, WASOP-CECAF).

The programme links FAO's normative work and global reporting with **regional implementation platforms** and six **thematic workstreams**, so that stock assessments routinely inform fleet capacity limits, effort management and harvest strategies. Its **cross-regional learning hub** connects regions and themes. The toolbox is the hub's **shared method library and code**: the common place where methods, data tools, guidance and training material are documented once and used by every region.
