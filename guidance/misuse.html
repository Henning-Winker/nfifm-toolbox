Misuse prevention

Caveats, assumptions and red flags across methods

A method that fits the data can still give misleading advice if its assumptions are violated. Each catalogue entry has a Misuse prevention section, and the method selector raises warnings for the situation you describe. This page lists all warning rules in one place.

  • Do not use: a core assumption is violated by the data; results should not be used for advice.
  • Caution: the method can be used, but only with the additional checks named.

Pre-run checks

Each catalogue entry now lists pre-run checks: concrete questions an analyst, or an app such as the Stock Monitoring Tool, should answer before a method is run, and what to do if a check fails. The idea goes back to the guidance for uses and misuses of data-limited methods developed by N. Gutierrez and K. Kleisner (2018) for the FAO online modules: for example, at least 20 years of catch with a peak away from the ends of the series before a catch-only method is run, or a representative length sample across habitats and gears before ELEFAN. The CMSY+ page includes an interactive catch-series check that applies these rules.

General red flags

  • Status depends mostly on priors or fixed inputs rather than data (prior and posterior nearly identical).
  • Good fit to data but poor prediction skill (hindcast MASE > 1).
  • Strong retrospective patterns (Mohn’s rho beyond about ±0.2).
  • Results inconsistent with the exploitation history or the biology of the stock.
  • A single “best” run reported without sensitivity analysis.

A method that fits the data can still give misleading advice if its assumptions are violated. Each catalogue entry has a **Misuse prevention** section, and the [method selector](../select/index.qmd) raises warnings for the situation you describe. This page lists all warning rules in one place.

- **Do not use:** a core assumption is violated by the data; results should not be used for advice.
- **Caution:** the method can be used, but only with the additional checks named.

```{r}
#| echo: false
source("R/toolbox.R")
r <- read_misuse()
m <- read_methods()
nm <- setNames(m$name, m$id)
r$Methods <- vapply(strsplit(r$methods, "|", fixed = TRUE),
                    function(x) if ("*" %in% x) "All methods" else paste(nm[x], collapse = ", "), "")
r$Severity <- ifelse(r$severity == "stop", "Do not use", "Caution")
r$`When` <- paste(r$question, "=", r$value)
DT::datatable(r[, c("Severity", "Methods", "When", "message")], rownames = FALSE,
              colnames = c("Severity", "Methods", "When", "Warning"), filter = "top",
              options = list(pageLength = 25, dom = "tip", scrollX = TRUE),
              class = "compact stripe hover")
```

## Pre-run checks

The idea goes back to the guidance for uses and misuses of data-limited methods developed by N. Gutierrez and K. Kleisner (2018) for the FAO online modules: for example, at least 20 years of catch with a peak away from the ends of the series before a catch-only method is run, or a representative length sample across habitats and gears before ELEFAN. The [CMSY+ page](../methods/biomass-dynamic/cmsy.qmd) includes an interactive catch-series check that applies these rules.

## General red flags

- Status depends mostly on priors or fixed inputs rather than data (prior and posterior nearly identical).
- Good fit to data but poor prediction skill (hindcast MASE > 1).
- Strong retrospective patterns (Mohn's rho beyond about ±0.2).
- Results inconsistent with the exploitation history or the biology of the stock.
- A single "best" run reported without sensitivity analysis.
