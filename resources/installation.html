R, Rtools, SPiCT, JABBA and JARA

Install and update r and rstudio

In general the lastest version of R and at least R 4.4 or higher is recommended. You can download the Windows version of R (Last version) The easier way to do this is by installing the package and accepting the default suggestions. You may be asked to install and update the packages in your previous version of R. You would want to allow it. The latest version is 4.4.1

Additionally, you might need to install or update Rstudio You may find the last version RStudio 2023.12.1+402

You can check the version of r with R.version You should retrieve the below information where version 4.3.2 is indicated

Note: Please make sure you have updated the version of R that rstudio runs. So, please in RStudio click the ‘Tools’ tab, go to ‘Global options’ and ‘R version’ to link the wished R version to RStudio.

Install Rtools

For any R version of 4.3.x, you need to select to install Rtools 43 and for R version 4.4.x, you need to install Rtools 44 Rtools. An exe file will be downloaded. Click on it and follow instructions.

To install SPiCT and JABBA from github needs some additional packages, first and foremost devtools and TMB (SPict)

Note that it is recommended to install TMB from type = source, which will also be required for running spict. The installation of TMB required that Rtools is correctly installed (see above)!

Code 
install.packages("devtools")
install.packages("TMB", type = "source")

SPiCT: Surplus Production models in Continuous-Time

SPiCT is an R-package for fitting surplus production models in continuous-time to fisheries catch data and biomass indices.

This package requires the installation of TMB and Rtools. Fortunately, these packages were already installed. In order to access the most recent version of spict that, among others, allows us to plot several scenarios at once, we will use the development branch.

Code 
devtools::install_github("DTUAqua/spict/spict", ref = "dev")

Test run spict

Testing SPiCT

Finally, we check that the last version of spict has been correctly installed. We call the data pre-loaded in the package, pol.

Code 
library(spict)
data(pol)
inp <- pol$hake
inp$dteuler =1/4
rep1 <- fit.spict(inp)
inp$priors$logbkfrac <- c(log(0.3), 0.1, 1)
rep2 <- fit.spict(inp)
plotspict.compare(list(def = rep1, bkprior = rep2))

Literature related to SPiCT can be found in SPiCT Github under the headline ‘Help files’, including:

    1. vignette for the package
    1. technical guidelines for using SPiCT
    1. published paper

Some examples of SPiCT for formal stock assessment in ICES are found below:

  • WKBMSYSPiCT

  • WKBMSYSPiCT2

  • Benchmark Workshop for selected elasmobranch stocks (WKBELASMO)

  • Good practices for surplus production models(Fish.Res.)

JARA: Just Another Red-list Assessment

JARA is a Bayesian state-space trend analysis tool. This tool was developed to support decisions regarding the extinction risk of threatened species, incorporating process error and uncertainty.

Please find some literature, including a description of the model, applications, and most recent implementation below:

  • JARA: Just Another Red-List Assessment

  • Estimating IUCN Red List population reduction: JARA

  • Half a century of global decline in oceanic sharks and rays

  • Coupling state-of-the-art modelling tools for better informed Red List assessments of marine fishes

  • The conservation status and population decline of the African penguin deconstructed in space and time

However, JARA has also established as a tool to create joint CPUE indices from multiple CPUE or survey indices as well as catch reconstructions with missing year/fleet records. For example, JARA can exactly reproduce the Hierarchical analysis of multiple noisy abundance indices by Conn, 2009 to create a joint index with estimated uncertainty

The General Fisheries Commission of the Mediterranean - recently adopted JARA to track the status of Mediterranean stocks

  • SoMFi 2025

Similarly, the Joint Research Centre (JRC) of the European Commission has adopted JARA for monitoring trends in stock status against the Common Fisheries Policy

  • Winker et al. 2022. Suitability study of the Bayesian State-Space model ‘JARA’ for stock status indicator estimation (STECF-Adhoc-22-02)

  • JRC 2024 Monitoring the Performance of the Common Fisheries Policy (STECF-Adhoc-24-01)

  • Winker H, Cardinale M, Gerritsen H, Herrera JG, Castellanos P, Farias I, Sampedro P, Moura T, Mosqueira I, Kell L. The ICES MSY approach to reference point estimation is not precautionary. ICES Journal of Marine Science. 2025 Nov;82(11):fsaf204.

Like JABBA, JARA requires JAGS to be installed

Code 
devtools::install_github("henning-winker/JARA")

## JARA: Just Another Red-list Assessment

[JARA](https://github.com/Henning-Winker/JARA) is a Bayesian state-space trend analysis tool. This tool was developed to support decisions regarding the extinction risk of threatened species, incorporating process error and uncertainty. 

Please find some literature, including a description of the model, applications, and most recent implementation below:

- [Half a century of global decline in oceanic sharks and rays](https://www.nature.com/articles/s41586-020-03173-9)

- [Coupling state-of-the-art modelling tools for better informed Red List assessments of marine fishes](https://besjournals.onlinelibrary.wiley.com/doi/10.1111/1365-2664.14601)

- [The conservation status and population decline of the African penguin deconstructed in space and time](https://onlinelibrary.wiley.com/doi/full/10.1002/ece3.6554)


However, `JARA` has also established as a tool to create joint CPUE indices from multiple CPUE or survey indices as well as catch reconstructions with missing year/fleet records. For example, JARA can exactly reproduce the Hierarchical analysis of multiple noisy abundance indices by [Conn, 2009](https://cdnsciencepub.com/doi/full/10.1139/F09-175?casa_token=yYzUyHEzE1gAAAAA%3AF6Pq5z316C4GADQqqemGSoaV5qCF-1VuVV4MDMtsFwi-0awVchtiFW1ovCER7vLut4SXo4hemg4) to create a joint index with estimated uncertainty
