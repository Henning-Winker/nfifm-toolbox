Catalogue structure

Standard fields for documenting each assessment method

Alongside the hierarchy, every method gets a standardised catalogue entry. The catalogue does more than list methods: it guides their responsible use by documenting data needs, pre-processing requirements, model assumptions, sensitivities, misuse prevention (when not to use a method, common misuses, a pre-use checklist and advice suitability) and the implementation resources available.

Catalogue of assessment methods

  • Method families with links to named methods
  • Biomass dynamic and dynamic pool branches, with equilibrium per-recruit and length-based age-structured sub-classes
  • Method entries that can be expanded with interactive tools

Concept: the catalogue complements the hierarchy. It documents what each method requires, how it should be prepared and interpreted, and where a mismatch between assumptions and data is likely to cause bias.
